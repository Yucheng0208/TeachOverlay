# TeachOverlay v1.1.0

**繁體中文** · [简体中文](#简体中文) · [English](#english) · [日本語](#日本語) · [한국어](#한국어)

這個版本加入了大量課堂工具：計時器、演講計時、上下課鐘聲、抽籤、全螢幕時鐘、黑屏、放大鏡與截圖標註，畫圖也變得更好用。

## 新功能

### 畫圖與白板
- **自動圖形**：隨手畫完停一下，自動變成工整的直線、圓形、方形、三角形或多邊形
- **尺**：可移動、旋轉，有公分刻度與角度，筆靠近尺邊就能畫直線
- **圓規**：拖出半徑後沿圓周畫圓或弧，並顯示半徑長度
- **更多白板背景**：白色、方格、深色、黑板綠、橫線、點格、黑板方格；換成黑板時筆會自動變白色
- **截圖標註**：選取範圍、視窗或整個螢幕截圖，直接在上面畫重點，存檔或拷貝貼到簡報

### 課堂工具
- **計時器**：倒數計時、番茄鐘、距離下一次鐘響，浮動顯示給全班看
- **演講計時**：綠、黃、紅燈號提醒講者；剩 2 分鐘、最後 1 分鐘、時間到分段提醒，超時會閃爍並顯示超出多久；可排講者名單，可浮動或全螢幕顯示在指定螢幕
- **距離下課**：選單列與畫圖工具列顯示距離下課還有多久
- **上下課鐘聲**：依課表自動打鐘，內建學校的西敏寺鐘聲，也可換成自己的音檔，並發送通知
- **抽籤**：匯入 txt 名冊、自訂學號格式或用座號抽；可排除已抽過與請假；可自動停止或由老師喊停
- **全螢幕時鐘**：數字或指針時鐘，可顯示在全部或指定的螢幕
- **黑屏**：讓投影畫面變黑，老師的筆電照常顯示
- **放大鏡**：局部放大游標附近的畫面

### 隱私
- 使用 LINE、Messenger、Instagram、Discord 等聊天或社群軟體時，完全不顯示按鍵
- 可自行加入其他不顯示按鍵的 App

### 其他
- 全新 App 圖示
- 所有浮動視窗的關閉鈕改到左上角，與 macOS 一致
- 「關於」頁加入作者資訊與連結
- 說明文件改為五種語言

## 新的快捷鍵

| 快捷鍵 | 功能 |
|---|---|
| ⌃⌥T | 計時器 |
| ⌃⌥V | 演講計時（顯示時 ⌃⌥Space 開始／暫停） |
| ⌃⌥R | 抽籤（滾動中再按一次即停止） |
| ⌃⌥L | 全螢幕時鐘 |
| ⌃⌥B | 黑屏 |
| ⌃⌥Z | 放大鏡 |
| ⌃⌥P | 截圖並標註 |

畫圖時：`U` 尺、`G` 圓規。

## 下載與安裝

| 檔案 | 說明 |
|---|---|
| `TeachOverlay-1.1.0-macOS-arm64.dmg` | 建議。打開後把 TeachOverlay 拖到「應用程式」資料夾 |
| `TeachOverlay-1.1.0-macOS-arm64.zip` | 解壓縮後把 TeachOverlay.app 移到「應用程式」資料夾 |

**系統需求**：macOS 13 Ventura 以上、Apple Silicon（M 系列晶片）Mac

**第一次打開**：此版本尚未經過 Apple 公證，macOS 會顯示「無法打開」。請到「系統設定 → 隱私權與安全性」，在下方找到 TeachOverlay，按「強制打開」。或在終端機執行：

```bash
xattr -dr com.apple.quarantine /Applications/TeachOverlay.app
```

**開啟權限**：到「系統設定 → 隱私權與安全性」開啟 TeachOverlay 的「輔助使用」、「輸入監控」；要用放大鏡與截圖標註，再開啟「螢幕錄製」。

**從舊版更新**：更新後若按鍵不顯示，請在上述設定中把 TeachOverlay 移除再重新加入。

## English

This release adds a full set of classroom tools: timer, speaker timer, class bell, random picker, full-screen clock, blackout, magnifier and screenshot annotation, plus better drawing.

### What's new

**Drawing & whiteboard**
- **Auto shapes**: draw roughly, hold still for a moment, and it turns into a clean line, circle, rectangle, triangle or polygon
- **Ruler**: move and rotate it, with centimeter ticks and an angle readout; draw near an edge for a straight line
- **Compass**: drag out a radius, then drag around to draw circles or arcs, with the radius shown
- **More backgrounds**: white, grid, dark, chalkboard, lined, dotted and chalkboard grid; the pen switches to white on dark boards
- **Screenshot and annotate**: capture a selection, window or whole screen, mark it up, then save or copy it into your slides

**Classroom tools**
- **Timer**: countdown, Pomodoro and time-until-bell, floating on screen for the whole class
- **Speaker timer**: green, yellow and red signals; reminders at 2 minutes left, the last minute and time up; flashes and counts overtime; speaker list; floating or full screen on chosen displays
- **Until class ends**: the menu bar and drawing toolbar show how long until class ends
- **Class bell**: rings on your schedule with a built-in Westminster school chime or your own sound, and sends a notification
- **Random picker**: import a txt roster, generate IDs from a pattern or use seat numbers; skip already-picked and absent students; stop automatically or when you say so
- **Full-screen clock**: digital or analog, on all or selected displays
- **Blackout**: blacks out the projector while your laptop screen stays on
- **Magnifier**: zooms in on the area around the cursor

**Privacy**
- No keystrokes are shown at all in chat and social apps such as LINE, Messenger, Instagram and Discord
- Add any other app you want to exclude

**Also**
- New app icon
- Close buttons on all floating windows moved to the top-left, as on macOS
- Author info and links on the About page
- Documentation in five languages

### New shortcuts

| Shortcut | Action |
|---|---|
| ⌃⌥T | Timer |
| ⌃⌥V | Speaker timer (⌃⌥Space starts/pauses while shown) |
| ⌃⌥R | Random picker (press again while rolling to stop) |
| ⌃⌥L | Full-screen clock |
| ⌃⌥B | Blackout |
| ⌃⌥Z | Magnifier |
| ⌃⌥P | Screenshot and annotate |

While drawing: `U` ruler, `G` compass.

### Download & install

| File | Notes |
|---|---|
| `TeachOverlay-1.1.0-macOS-arm64.dmg` | Recommended. Open it and drag TeachOverlay to Applications |
| `TeachOverlay-1.1.0-macOS-arm64.zip` | Unzip and move TeachOverlay.app to Applications |

**Requirements**: macOS 13 Ventura or later on an Apple Silicon (M-series) Mac

**First launch**: this build is not notarized by Apple yet, so macOS will say it can't be opened. Go to **System Settings → Privacy & Security**, find TeachOverlay near the bottom and click **Open Anyway**. Or run in Terminal:

```bash

```

**Permissions**: in **System Settings → Privacy & Security**, turn on TeachOverlay under **Accessibility** and **Input Monitoring**; for the magnifier and screenshot annotation, also turn on **Screen Recording**.

**Updating**: if keystrokes don't show after updating, remove TeachOverlay from those lists and add it again.

## 日本語

このバージョンでは、タイマー、スピーチタイマー、授業のチャイム、くじ引き、全画面時計、ブラックアウト、拡大鏡、スクリーンショットへの描き込みなど、授業向けのツールを多数追加し、描画も使いやすくなりました。

### 新機能

**描画とホワイトボード**
- **自動図形**：手描きしたあと少し止めると、きれいな直線・円・四角形・三角形・多角形に変わります
- **定規**：移動・回転でき、センチの目盛りと角度を表示。辺の近くで描くと直線になります
- **コンパス**：半径をドラッグで決め、円周に沿って円や弧を描けます。半径も表示します
- **背景の追加**：白、方眼、ダーク、黒板、罫線、ドット、黒板（方眼）。黒板ではペンが自動で白になります
- **スクリーンショットに描き込み**：範囲・ウインドウ・画面全体を撮影してそのまま描き込み、保存やコピーでスライドに貼り付け

**授業のツール**
- **タイマー**：カウントダウン、ポモドーロ、次のチャイムまでを画面に浮かべてクラス全員に表示
- **スピーチタイマー**：緑・黄・赤のサインで発表者に知らせ、残り 2 分・残り 1 分・時間切れで通知。超過すると点滅して超過時間を表示。発表者リスト、フローティングまたは指定画面への全画面表示に対応
- **授業終了まで**：メニューバーと描画ツールバーに授業終了までの時間を表示
- **授業のチャイム**：時間割どおりに自動で鳴らします。学校のウェストミンスターの鐘を内蔵、好きな音にも変更でき、通知も表示
- **くじ引き**：txt の名簿読み込み、学籍番号の形式指定、出席番号から抽選。抽選済みや欠席を除外でき、自動で止めるか先生がストップするかを選べます
- **全画面時計**：デジタルまたはアナログ。すべての画面か選んだ画面に表示
- **ブラックアウト**：プロジェクターを黒くし、先生のノートはそのまま表示
- **拡大鏡**：カーソル周辺を拡大します

**プライバシー**
- LINE、Messenger、Instagram、Discord などのチャット・SNS アプリではキーを一切表示しません
- キーを表示しないアプリを自分で追加できます

**その他**
- 新しいアプリアイコン
- すべてのフローティングウインドウの閉じるボタンを macOS と同じ左上に移動
- 「情報」ページに作者の情報とリンクを追加
- 説明書を 5 言語に対応

| ⌃⌥R | くじ引き（回転中にもう一度押すとストップ） |
| ⌃⌥L | 全画面時計 |

描画中：`U` 定規、`G` コンパス。

### ダウンロードとインストール

| ファイル | 説明 |
|---|---|
| `TeachOverlay-1.1.0-macOS-arm64.dmg` | おすすめ。開いて TeachOverlay を「アプリケーション」にドラッグ |
| `TeachOverlay-1.1.0-macOS-arm64.zip` | 展開して TeachOverlay.app を「アプリケーション」に移動 |

**動作環境**：macOS 13 Ventura 以降、Apple Silicon（M シリーズ）搭載 Mac

**初回起動**：このバージョンはまだ Apple の公証を受けていないため、「開けません」と表示されます。「システム設定 → プライバシーとセキュリティ」の下部で TeachOverlay を見つけ、「このまま開く」をクリックしてください。またはターミナルで次を実行します：


## 한국어

이번 버전에는 타이머, 발표 타이머, 수업 종, 뽑기, 전체 화면 시계, 화면 끄기, 돋보기, 스크린샷 주석 등 수업용 도구가 대거 추가되었고 그리기도 더 편리해졌습니다.

### 새로운 기능

**그리기 및 화이트보드**
- **자동 도형**: 대충 그린 뒤 잠시 멈추면 반듯한 직선, 원, 사각형, 삼각형, 다각형으로 바뀝니다
- **자**: 옮기고 돌릴 수 있으며 센티미터 눈금과 각도를 표시합니다. 가장자리 근처에서 그리면 직선이 됩니다
- **컴퍼스**: 반지름을 드래그한 뒤 원을 따라 드래그해 원이나 호를 그리고, 반지름도 표시합니다
- **배경 추가**: 흰색, 모눈, 어두운색, 칠판, 줄, 점, 칠판 모눈. 어두운 배경에서는 펜이 자동으로 흰색이 됩니다
- **스크린샷 주석**: 선택 영역, 윈도우, 전체 화면을 캡처해 바로 표시하고 저장하거나 복사해 슬라이드에 붙여 넣기

**수업 도구**
- **타이머**: 카운트다운, 뽀모도로, 다음 종까지 남은 시간을 화면에 띄워 반 전체가 볼 수 있습니다
- **발표 타이머**: 초록·노랑·빨강 신호로 발표자에게 알리고, 2분 남음·마지막 1분·시간 종료에 알림. 초과하면 깜빡이며 초과 시간을 표시. 발표자 목록, 플로팅 또는 지정한 화면에 전체 화면 표시 지원
- **수업 끝까지**: 메뉴 막대와 그리기 도구 막대에 수업이 끝날 때까지 남은 시간 표시
- **수업 종**: 시간표대로 자동으로 종을 울립니다. 학교 웨스트민스터 차임 내장, 원하는 소리로 바꿀 수 있으며 알림도 보냅니다
- **뽑기**: txt 명단 가져오기, 학번 형식 지정, 번호로 뽑기. 이미 뽑힌 사람과 결석자를 제외하고, 자동으로 멈추거나 선생님이 멈출 수 있습니다
- **전체 화면 시계**: 디지털 또는 아날로그로 모든 화면이나 선택한 화면에 표시
- **화면 끄기**: 프로젝터 화면을 검게 하고 선생님 노트북은 그대로 보입니다
- **돋보기**: 커서 주변을 확대합니다

**개인정보 보호**
- LINE, Messenger, Instagram, Discord 같은 채팅·SNS 앱에서는 키를 전혀 표시하지 않습니다
- 키를 숨길 앱을 직접 추가할 수 있습니다

**그 밖에**
- 새 앱 아이콘
- 모든 플로팅 윈도우의 닫기 버튼을 macOS처럼 왼쪽 위로 이동
- '정보' 페이지에 만든 사람 정보와 링크 추가

### 새 단축키

| 단축키 | 기능 |
|---|---|
| ⌃⌥T | 타이머 |
| ⌃⌥V | 발표 타이머 (표시 중 ⌃⌥Space로 시작/일시 정지) |
| ⌃⌥R | 뽑기 (돌아가는 중 다시 누르면 멈춤) |
| ⌃⌥L | 전체 화면 시계 |
| ⌃⌥B | 화면 끄기 |
| ⌃⌥Z | 돋보기 |
| ⌃⌥P | 스크린샷 후 주석 |

그리는 중: `U` 자, `G` 컴퍼스.
