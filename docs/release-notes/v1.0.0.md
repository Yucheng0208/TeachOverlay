# TeachOverlay v1.0.0

**繁體中文** · [简体中文](#简体中文) · [English](#english) · [日本語](#日本語) · [한국어](#한국어)

上課、錄影、直播時，讓觀眾看清楚你在按什麼、點哪裡。TeachOverlay 是 Apple Silicon 原生的 macOS 教學螢幕助手。

## 功能

- **放大顯示按鍵**：打字與組合鍵即時放大顯示，可調整字體大小、位置與停留時間
- **組合鍵說明**：顯示成「Command + C 複製」，也可改用符號 ⌘C；常見快捷鍵自動附上功能說明
- **快捷鍵懸停**：組合鍵堆疊在左上或右上角，可設定保留秒數或一直保留
- **注音支援**：先顯示注音，選字後顯示中文
- **隱私保護**：密碼、帳號、學號等欄位只顯示「已隱藏」，關鍵字可自訂
- **滑鼠效果**：雙擊脈衝（顏色、大小、速度可調）、左／右／中鍵提示、長按圓圈
- **聚光燈**：周圍變暗，只照亮游標附近
- **畫圖標註與白板**：畫筆、螢光筆、直線、箭頭、方框、圓形；白板支援多頁並可存成 PNG
- **筆記**：寫講稿或重點，可浮動顯示在畫面最上層
- **多螢幕同步**：按鍵與快捷鍵同步顯示在所有螢幕，全螢幕 App 也會顯示
- **五種語言**：繁體中文、简体中文、English、日本語、한국어（預設跟隨系統）
- **明亮／暗黑模式**：App 與螢幕提示配色皆可跟隨系統

## 快捷鍵

| 快捷鍵 | 功能 |
|---|---|
| ⌃⌥K | 顯示按鍵 開／關 |
| ⌃⌥C | 雙擊脈衝 開／關 |
| ⌃⌥S | 聚光燈（Esc 也可關閉） |
| ⌃⌥D | 畫圖標註 |
| ⌃⌥W | 白板 |
| ⌃⌥X | 關閉全部效果 |

## 下載與安裝

| 檔案 | 說明 |
|---|---|
| `TeachOverlay-1.0.0-macOS-arm64.dmg` | 建議。打開後把 TeachOverlay 拖到「應用程式」資料夾 |
| `TeachOverlay-1.0.0-macOS-arm64.zip` | 解壓縮後把 TeachOverlay.app 移到「應用程式」資料夾 |

**系統需求**：macOS 13 Ventura 以上、Apple Silicon（M 系列晶片）Mac

**第一次打開**：此版本尚未經過 Apple 公證，macOS 會顯示「無法打開」。請到「系統設定 → 隱私權與安全性」，在下方找到 TeachOverlay，按「強制打開」。或在終端機執行：

```bash
xattr -dr com.apple.quarantine /Applications/TeachOverlay.app
```

**開啟權限**：到「系統設定 → 隱私權與安全性」，開啟「輔助使用」與「輸入監控」中的 TeachOverlay。開啟後約 2 秒內生效，不需重新啟動。

## English

Let your audience see exactly what you press and click while teaching, recording or streaming. TeachOverlay is a native Apple Silicon screen assistant for teaching on macOS.

### Features

- **Large keystroke display**: typing and shortcuts shown large in real time, with adjustable size, position and duration
- **Shortcut descriptions**: shown as “Command + C Copy” (or symbols like ⌘C), with descriptions for common shortcuts
- **Shortcut history**: shortcuts stack in the top-left or top-right corner, for a set time or until cleared
- **Zhuyin support**: shows Bopomofo first, then the chosen Chinese characters
- **Privacy protection**: password, account, student ID and similar fields only show “Hidden”; keywords are customizable
- **Mouse effects**: double-click pulses (adjustable color, size, speed), left/right/middle button badge, long-press ring
- **Spotlight**: dims everything except the area around the cursor
- **Annotation & whiteboard**: pen, highlighter, line, arrow, rectangle, ellipse; multi-page whiteboard with PNG export
- **Notes**: write scripts or key points and float them above everything
- **Multi-display sync**: keystrokes and shortcuts appear on every display, including full-screen apps
- **Five languages**: Traditional Chinese, Simplified Chinese, English, Japanese, Korean (follows the system by default)
- **Light / dark mode**: the app and on-screen hints follow the system appearance

### Shortcuts

| Shortcut | Action |
|---|---|
| ⌃⌥K | Keystrokes on/off |
| ⌃⌥C | Click pulse on/off |
| ⌃⌥S | Spotlight (Esc also turns it off) |
| ⌃⌥D | Annotate |
| ⌃⌥W | Whiteboard |
| ⌃⌥X | Turn off all effects |

### Download & install

| File | Notes |
|---|---|
| `TeachOverlay-1.0.0-macOS-arm64.dmg` | Recommended. Open it and drag TeachOverlay to Applications |
| `TeachOverlay-1.0.0-macOS-arm64.zip` | Unzip and move TeachOverlay.app to Applications |

**Requirements**: macOS 13 Ventura or later on an Apple Silicon (M-series) Mac

**First launch**: this build is not notarized by Apple yet, so macOS will say it can't be opened. Go to **System Settings → Privacy & Security**, find TeachOverlay near the bottom and click **Open Anyway**. Or run in Terminal:

```bash
xattr -dr com.apple.quarantine /Applications/TeachOverlay.app
```

**Permissions**: in **System Settings → Privacy & Security**, turn on TeachOverlay under **Accessibility** and **Input Monitoring**. It takes effect within about 2 seconds, no restart needed.

## 日本語

授業・録画・配信で、何を押してどこをクリックしたかを視聴者にはっきり見せます。TeachOverlay は Apple Silicon ネイティブの macOS 向け授業用画面アシスタントです。

### 機能

- **キーの拡大表示**：入力とショートカットをリアルタイムで大きく表示。サイズ・位置・表示時間を調整可能
- **ショートカットの説明**：「Command + C コピー」のように表示（記号 ⌘C にも切替可）。よく使うショートカットには説明を自動表示
- **ショートカット履歴**：左上または右上に積み上げて表示。一定時間または消去まで保持
- **注音入力に対応**：先に注音記号、変換後に漢字を表示
- **プライバシー保護**：パスワード・アカウント・学籍番号などの欄は「非表示」とだけ表示。キーワードは変更可能
- **マウス効果**：ダブルクリック波紋（色・サイズ・速さを調整可）、左／右／中央ボタン表示、長押しの円
- **スポットライト**：カーソル周辺以外を暗くします
- **描画とホワイトボード**：ペン、蛍光ペン、直線、矢印、四角形、円。ホワイトボードは複数ページで PNG 保存可能
- **メモ**：原稿やポイントを書き、最前面に浮かべて表示
- **複数ディスプレイ同期**：キーとショートカットをすべての画面に表示。フルスクリーン App にも表示
- **5 言語対応**：繁体字中国語、簡体字中国語、英語、日本語、韓国語（既定はシステムに従う）
- **ライト／ダークモード**：App と画面上の表示がシステムの外観に追従

### ショートカット

| ショートカット | 機能 |
|---|---|
| ⌃⌥K | キー表示 オン／オフ |
| ⌃⌥C | クリック波紋 オン／オフ |
| ⌃⌥S | スポットライト（Esc でもオフ） |
| ⌃⌥D | 画面に描画 |
| ⌃⌥W | ホワイトボード |
| ⌃⌥X | すべての効果をオフ |

### ダウンロードとインストール

| ファイル | 説明 |
|---|---|
| `TeachOverlay-1.0.0-macOS-arm64.dmg` | おすすめ。開いて TeachOverlay を「アプリケーション」にドラッグ |
| `TeachOverlay-1.0.0-macOS-arm64.zip` | 展開して TeachOverlay.app を「アプリケーション」に移動 |

**動作環境**：macOS 13 Ventura 以降、Apple Silicon（M シリーズ）搭載 Mac

**初回起動**：このバージョンはまだ Apple の公証を受けていないため、「開けません」と表示されます。「システム設定 → プライバシーとセキュリティ」の下部で TeachOverlay を見つけ、「このまま開く」をクリックしてください。またはターミナルで次を実行します：

```bash

```

**権限の許可**：「システム設定 → プライバシーとセキュリティ」で「アクセシビリティ」と「入力監視」の TeachOverlay をオンにします。約 2 秒以内に有効になり、再起動は不要です。

## 한국어

수업, 녹화, 방송 중에 무엇을 누르고 어디를 클릭하는지 시청자가 잘 보이게 합니다. TeachOverlay는 Apple Silicon 네이티브 macOS 수업용 화면 도우미입니다.

### 기능

- **키 크게 표시**: 입력과 단축키를 실시간으로 크게 표시하며 크기, 위치, 표시 시간을 조절할 수 있습니다
- **단축키 설명**: 'Command + C 복사'처럼 표시하며(기호 ⌘C로도 전환 가능) 자주 쓰는 단축키에는 설명이 붙습니다
- **단축키 기록**: 왼쪽 위나 오른쪽 위에 쌓이며 정한 시간 동안 또는 지울 때까지 유지됩니다
- **주음 입력 지원**: 먼저 주음 부호를, 변환 후 한자를 표시합니다
- **개인정보 보호**: 비밀번호, 계정, 학번 등의 칸은 '숨김'으로만 표시되며 키워드는 직접 정할 수 있습니다
- **마우스 효과**: 더블클릭 파동(색상, 크기, 속도 조절), 왼쪽/오른쪽/가운데 버튼 표시, 길게 누르기 원
- **스포트라이트**: 커서 주변만 밝히고 나머지를 어둡게 합니다
- **화면 주석 및 화이트보드**: 펜, 형광펜, 직선, 화살표, 사각형, 원. 화이트보드는 여러 페이지이며 PNG로 저장할 수 있습니다
- **메모**: 대본이나 요점을 적고 맨 위에 띄워 볼 수 있습니다
- **여러 화면 동기화**: 키와 단축키가 모든 화면에 표시되며 전체 화면 앱에도 표시됩니다
- **5개 언어**: 번체 중국어, 간체 중국어, 영어, 일본어, 한국어 (기본값은 시스템 설정 따르기)
- **라이트/다크 모드**: 앱과 화면 표시가 시스템 화면 모드를 따릅니다
